Keyman input check

Type your own real orthography with your own keyboard — there is no target string and nothing here knows what is "correct". The test is consistency: type a line, press Enter to record it — in the middle box (textarea) use Shift+Enter, because plain Enter has to stay a newline there — then type the same line again. Identical typing must produce identical codepoints. Do a few hundred keystrokes in each of the three boxes.

The repeat mismatches box is the verdict. "Swallowed" and "spurious" are hints only: a keystroke that produced no text, and text that appeared with no keystroke. Some keyboards legitimately do both (dead keys, reordering, composition), so read them alongside the log — not as failures on their own.
